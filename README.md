# 🧠 CNN Vision 🚀  
**A Professional In-Browser Deep Learning Workbench**

CNN Vision is an interactive, browser-based Deep Learning playground built with **TensorFlow.js**, designed to demonstrate **Computer Vision, CNN training, inference, and explainability** — all without leaving your browser.

This project is a **passion + skill fusion**, created during leisure time as a break from continuously studying ML/DL theory and models. The goal was to **turn learning into something visual, interactive, and enjoyable**.

## ✨ Key Features

### 🔍 1. Advanced Inference Engine
- **Multi-Model Support**
  - MobileNet v2  
  - ResNet-50  
  - EfficientNet  
  - InceptionV3  
- **Real-Time Image Classification**
  - Drag & Drop image upload  
  - Webcam capture for instant predictions  
- **Privacy-First Design**
  - 100% client-side processing  
  - No image uploads, no server dependency  

---

### 📂 2. Batch Image Processing Dashboard
- Upload **multiple images at once**
- Automated batch inference
- Tabular results including:
  - Top predicted class  
  - Confidence score  
  - Inference latency (ms)
- Ideal for comparing performance across images and models  

---

### 🧠 3. In-Browser CNN Training Workbench
- **Train a CNN from scratch directly in the browser**
- Dataset options:
  - Built-in **MNIST** dataset  
  - Custom CSV upload (`label, pixel1 ... pixel784`)
- **Live Training Visualization**
  - Real-time Accuracy curve  
  - Real-time Loss curve  
- No Python, no backend, no installations required  

---

### 🎨 4. Model Explainability with Grad-CAM
- **Saliency & Attention Visualization**
- Heatmap overlays show *where the model is looking*
- Toggle Grad-CAM on/off for any prediction
- Helps bridge the gap between **black-box models and interpretability**

---

### 🧩 5. User Experience & Design
- Modern **Dark UI Theme**
- Smooth interactions & responsive layout
- Clean dashboards for training, inference, and visualization
- Designed to feel like a **mini deep learning lab**

## 🏃‍♂️ How to Run Locally

1. Clone the repository:
   ```bash
   git clone https://github.com/UmmayMaimonaChaman/CNN-Image-Classifier
2. Navigate to the project folder
   ```bash
   cd CNN-Image-Classifier
3. Open index.html using any modern browser
(Chrome / Edge / Firefox recommended)

⚠️ **Important Note:**  
For **webcam access**, most browsers block the `file://` protocol.  
Please use a local server such as:
- **VS Code Live Server**
- Any **localhost HTTP server**
