Model Explainability (Grad-CAM)

Grad-CAM creates a heatmap highlighting the regions of the image that led to the prediction.

How it works

We compute the gradient of the winning class score with respect to the feature maps of the last convolutional layer. These gradients tell us how important each feature map is. We weight the maps and generate a heatmap.
Note: This requires the custom trained model or compatible layer access.
